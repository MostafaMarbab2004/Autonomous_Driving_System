2. How the Data Transforms

Neural networks require fixed-size, structured inputs. However, LiDAR data comes as an unstructured "Point Cloud" — an array of 1024 distinct points in 3D space [X, Y, Z]. Passing this directly to a traditional multi-layer perceptron (MLP) is highly inefficient and loses spatial meaning.

Therefore, we pass it through a custom PointNet module inside the agent:

  • Step A: The agent reshapes the incoming flat array back into precisely 1024 points.
  • Step B: A specialized Mini-Neural Network acts on every individual point in isolation, projecting its [X,Y,Z] coordinates into a 64-dimensional feature representation.
  • Step C: We apply a mathematically symmetric Max-Pooling operation across all 1024 point features. This crushes the entirety of the point cloud down into exactly 64 global features.

3. Final Tensor Sizes

Before making a decision, the PPO agent fuses these three distinct senses into one single perception vector:

Source Description Vector Size
Camera Processed through pre-trained VAE encoder (beta-VAE). 128
Telemetry Vehicle dynamics (Speed and Steering angle). 2
LiDAR Processed via our new PointNet feature extractor. 64
Total Final fused observation dimension sent to Actor/Critic MLPs. 194

4. Training Implications

Because the PointNet Extractor is built directly into the start of the Actor and Critic modules respectively, it calculates gradients automatically during the PPO rollout updates. Over thousands of episodes, the backpropagation will dynamically teach the PointNet exactly which spatial features indicate an impending collision (a negative reward) and adjust its weights.
